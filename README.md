# WORD2VEC FROM SCRATCH WITHOUT ANY MODULES EXCEPT NUMPY
A custom basic Word2Vec-style word embedding and vector similarity search engine built from scratch in pure Python using sliding-window training, MSE loss optimization, and cosine similarity.

This is basic implementation . I have not used Self Attention or Binary Cross Entropy Loss. As a result , the output is not very accurate. However as this is my first project of embeddings and tokenization , I focussed more on hands on implementation.

Loss function used - Mean Square Error
Module used - NUMPY ( for DOT PRODUCT SCORING)
